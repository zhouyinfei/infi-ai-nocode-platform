# 后端日志说明

后端使用 Spring Boot 自带的 SLF4J 日志体系，默认输出到控制台。

- `INFO`：注册和登录成功、应用创建、任务开始与完成、构建、发布、截图、定时清理及服务启停。
- `WARN`：生成或构建失败、任务容量不足、发布元数据写入失败、截图失败及服务重启后的任务恢复。
- `ERROR`：统一异常处理器捕获的未知请求故障。
- `DEBUG`：任务阶段、请求去重、权限拒绝、限流、预览票据签发及 SSE 订阅断开。

生成问题优先按 `appId`、`taskId` 检索；构建日志使用 `artifactId` 关联产物目录，发布日志包含 `version`。`elapsedMs` 使用单调时钟计算耗时。删除事务日志中的 `status` 是 Spring 事务完成状态：0 表示提交，1 表示回滚，2 表示未知。

需要详细日志时，可在本地配置添加以下内容，并在排查结束后恢复默认级别：

```yaml
logging:
  level:
    org.infi.nocode: DEBUG
```

日志不输出密码、模型密钥、Cookie、会话标识、预览票据、完整提示词、聊天正文或生成源码。异常通常只记录类型，避免第三方异常消息泄漏凭据或用户内容。高频 token、心跳和正常静态资源访问不逐条记录。

模型请求和响应元数据仍由现有 `log-requests`、`log-responses` 配置控制。截图失败不代表发布失败，应分别查看发布激活与截图结果。
